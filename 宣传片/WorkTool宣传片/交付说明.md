# WorkTool 产品宣传片

- 52 秒，16:9 横屏，30fps。
- 主交付：宣传片 4K.mp4（3840×2160）。
- 分享版：宣传片 1080p.mp4（1920×1080）。
- 纯音乐 + 音效 + 中文大字幕，无旁白。
- 网页版/ 为同源交互播放页，工程/ 保留完整 Remotion 源码、截图、配乐与校验记录。

## 本地打开网页版
在本目录运行：
    npx --yes http-server 网页版 -p 18769 -a 127.0.0.1 -c-1
再用浏览器访问 http://127.0.0.1:18769 。

## 素材说明
页面为用户产品线上真实页面的本地高清快照，账号、客户消息、接口与令牌等已遮盖。
配乐 Mixkit #173，用于网站、社交媒体及在线广告，许可详见调研笔记.md。
如要投放电视、广播、游戏、CD/DVD，应先更换适用许可的配乐。

## 修改与再导出
工程/src/timing.json：分镜与节拍。
工程/src/scenes/Design.tsx：字幕、镜头与版式。
工程/scripts/mix.py：声音事件。
工程/public/shots：脱敏页面截图。
npm run render:4k 导出，npm run web:build 构建网页。
