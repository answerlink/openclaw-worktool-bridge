# 管理员手册

管理员入口受账号权限、部署模式和模块开关控制。下面说明当前平台的管理能力；独立部署未开启的模块不会出现在菜单中。

## 用户管理

查看账号、企业、注册与登录时间、绑定机器人；可以创建普通用户、修改普通用户密码、停用或重新启用账号。停用会使该普通用户的现有登录态失效，管理员账号禁止被停用。

独立部署关闭自助注册时，由管理员创建用户。首次管理员的初始化方式见[部署运维](/docs/deploy.html)。

## 站内信

「站内信配置」支持新增、编辑、发布、下线和删除，内容为纯文本。接收范围可选全部用户、仅管理员或指定手机号。用户在左下角「站内信」查看。

系统还会生成部分通知，例如授权到期提醒。人工公告先核对接收范围再发布。

## 机器人排查与测试回调

- 「机器人排查」按机器人和时间核对服务端记录。
- 「客户端日志」可按消息 ID 请求日志；能否取得日志取决于客户端能力、在线状态和日志是否仍存在。
- 「测试回调地址」提供请求接收与查看工具，记录时间、请求方、方法及请求体。它用于检查请求有没有到达，不会替代业务事件处理。

排查时先确定时间、机器人 ID 和 messageId，避免只凭在线状态判断某条指令是否成功。

## 业务与发布管理

| 入口 | 用途和操作要点 |
| --- | --- |
| 机器人迁移等管理操作 | 新增、续期、停用或转换机器人 ID；先核对来源、目标与确认框 |
| 企业定制开通 | 查询、新增、修改和删除企业授权；按页面提供的分享或导出能力交付 |
| App管理 | 新增客户端版本，维护下载地址、版本号与更新说明，确认后启用 |
| 线下订单登记 | 登记人工核验的付款及交付信息，不与支付渠道自动同步 |
| 管理员审计日志 | 查看受审计的管理操作，核对操作人与时间 |
| 后端节点 | 查看连接、就绪状态、负载及详情；节点上下线会影响服务接入，应按运维流程执行 |

App 版本的展示名称与内部版本号用途不同，启用前应确认下载包、下载地址及版本信息对应一致。线下订单的新增、修改和删除会写入审计记录。

## 黑名单与授权

IP 黑名单管理需要对应模块开关及 WorkTool 接口配置。企业授权同样依赖后端接口；Console 页面可见不代表部署环境已经提供这些服务。

私有化授权签发支持 RSA-SHA256 的 V2 `license.lic`，并保留 V1 AES 格式供旧服务使用。V2 签发私钥仅应配置在负责签发的 SaaS 后端，不能放进客户部署包或前端。

## 演示机器人

`DEMO_ROBOT_IDS` 标识演示机器人。普通用户可查看及测试下发指令，但配置修改受到限制；管理员可以按权限维护。它不是完全不可操作的只读模式，不能用来隔离真实业务机器人。

## 数据维护

备份整个 Console 数据库、上传目录和部署配置，而不是只备份少数日志表。机器人、回复规则、引擎、标签、定时任务、事件任务、站内信等都可能需要恢复。

业务数据与密钥分开保护，定期验证恢复过程。环境变量及模块开关的完整清单见[环境变量参考](/docs/env-reference.html)。
