# 指令下发与查询

## 立即下发

进入「指令任务下发」，选择机器人和动作，填写参数后提交。主要动作包括发送文本、发送图片或文件、创建外部群、修改群、解散群、手机号加好友及清理存储。

| 动作 | 填写重点 |
| --- | --- |
| 发送文本 | 目标名称或标签、内容；按需填写 @ 对象 |
| 发送图片或文件 | 文件名、下载地址、文件类型；可带文本 |
| 创建外部群 | 新群名、成员；按需填写群公告、备注等 |
| 修改群 | 目标群名或备注，以及改名、增减成员、公告等变更 |
| 手机号加好友 | 手机号及按需填写的备注、标签、留言 |

文件下载地址需可被执行链路访问。图片类型填写 `image`，一般文件可使用 `*`；文件名应保留正确扩展名。需要附带文字时填写「附带文本消息（可选）」。

群操作与清理操作会改变实际客户端状态。先核对机器人和目标，再提交。

## 保存消息 ID

提交响应中的 messageId 用于关联后续执行结果。提交成功表示 WorkTool 接受了请求，不代表手机已完成。多目标任务可能包含多项结果，应检查失败明细。

## 指令任务查询

选择同一机器人，可按状态或消息 ID 查找。当前查询范围为最近 2 天、最多 2000 条指令；待执行等页面会定期刷新。

| 状态 | 如何理解 |
| --- | --- |
| 待执行 | 尚无明确完成结果，可能仍排队或等待反馈 |
| 成功 | 已取得相应成功反馈 |
| 失败 | 查看客户端返回原因及成功/失败明细 |
| 已终止 | 已识别取消相关记录；不代表回滚已执行动作 |

长时间待执行先确认在线情况、任务队列和日志。不要仅因暂未收到反馈就重复创建群或重复发送。

## 取消待执行任务

页面支持取消选中的待执行任务或清理待执行队列。平台会再次检查状态，但取消与客户端执行可能同时发生。已开始或已完成的操作不能靠取消队列撤回。

按时间触发见[定时任务](/docs/scheduled-tasks.html)，按事件触发见[事件任务](/docs/event-tasks.html)。
