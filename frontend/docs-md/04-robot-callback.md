# 机器人与回调配置

## 添加机器人

在“机器人配置”中点击“添加机器人”。

建议：

- 初期先开启私聊回复
- 群聊先在测试群验证后再放开

## 小白模式

在「机器人信息」→「机器人使用设置」中选择「小白模式」。

1. 点击「一键接入平台」，无需手动填写消息回调地址。
2. 到「机器人配置」中开启需要的私聊 / 群聊回复，并设置回复规则。
3. 如需监控安卓设备上 WorkTool 机器人的上线和掉线情况，配置可选的「上下线群通知」。

### 配置上下线群通知

1. 打开企业微信客户端，进入一个**内部群**。
2. 点击右上角「更多（···）」→「消息推送」→「添加」。
3. 新建消息推送机器人，名称可填「WorkTool 上下线通知」。
4. 复制完整的 Webhook 地址，并完成企业微信里的保存。
5. 回到本平台，粘贴到「消息推送机器人的 Webhook 地址」，点击「保存群通知」。

保存会同时配置上线和掉线通知，两类通知都会发送到这个群。页面内提供图文操作指引，不需要通知时可跳过这一步。

## 自定义模式

已有自己的接收服务时，选择「自定义模式」，按需设置消息、指令执行结果、群二维码和上下线回调。

切换模式只改变界面，不会自动修改已保存的配置。已有自定义消息地址的机器人会优先显示自定义模式；点击「一键接入平台」才会将消息接收方改成本平台。

保存或接入平台时，如果将替换已有的非空地址，会先展示原地址、新地址和受影响的回调类型，请你二次确认。空地址首次配置或保存相同地址无需确认，取消则保留原配置。

小白模式隐藏指令执行结果、群二维码和回调明细，自定义模式仍可查看、测试、保存或删除这些配置。平台消息接收地址统一显示为「由本平台接收消息」，无需手动查看或复制；自定义地址按原样显示。需要替换平台接收方时，在自定义模式点击「填写自定义地址」。

## 群二维码回调说明

当机器人收到群二维码时，平台会向配置的回调地址发送 POST 请求，Content-Type 为 application/json。

示例请求体：

```json
{
  "messageId": "1942501372444566650",
  "type": 207,
  "qrCode": "https://c.weixin.com/g/rlaIbU-GvukjXx",
  "groupName": "华东客户服务交流群"
}
```

## 常见问题

- 保存失败：检查地址是否可访问、证书是否正常
- 收不到消息：检查 WorkTool 侧是否确实绑定到目标地址
