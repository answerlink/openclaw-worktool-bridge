# 定时任务

定时任务由服务端调度器执行，保存后不需要一直打开浏览器。安卓机器人仍需在线并能够执行相应指令。

## 创建任务

1. 选择机器人，填写任务名称。
2. 选择动作，填写目标和内容等参数。
3. 选择执行时间及时间类型。
4. 核对时区、下次运行时间和启用状态，保存。

动作按页面选项填写，包含消息与群操作等。任务中的标签目标在执行时解析，新增群是否被包含取决于届时的标签和群数据。

## 时间类型

| 类型 | 用法 |
| --- | --- |
| 单次 | 指定一个日期时间 |
| 每天 | 每天固定时刻 |
| 每周 | 选择星期和时刻 |
| Cron | 使用 5 段表达式：分、时、日、月、星期 |

默认时区为 `Asia/Shanghai`。例如 `0 9 * * *` 表示每天 09:00；不要填写带秒的 6 段表达式。

当前实现的星期数字为 `0=周一` 到 `6=周日`，与常见 Unix Cron 的星期编号不同；日期与星期同时限制时需要同时满足。支持 `*`、逗号、范围与步长，不支持英文星期或月份名称。每周固定执行优先使用“每周”选项，避免表达式歧义。

## 错过执行时间

任务可选择跳过或补执行一次。当前调度对超过 10 分钟的延迟按错过策略处理；较短延迟仍可能执行。补执行一次不是补齐停机期间的每一次历史运行。

机器人离线与调度器错过时间是不同情况：调度提交后，客户端能否及时完成还需查看指令结果。

## 运行与维护

通过页面查看运行记录，按需暂停、恢复或立即执行。立即执行会产生真实动作，不只是配置预览。单次任务完成调度后不会周期重复。

运行记录反映调度和提交情况，最终结果用 messageId 到「指令任务查询」核对。结果不明时先查记录，再决定是否补发。

事件任务的日期变量和多动作能力不应直接套用到定时任务字段；以该页面实际提供的选项为准。
