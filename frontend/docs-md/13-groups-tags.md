# 群列表与标签

## 群列表里的数据

「群列表」展示平台已同步的群信息，包括群名、群备注、群主、成员数、消息数、时间及公告等。群备注为空时显示占位符；它不是群名称的替代列。

列表来自 WorkTool 已上报的数据，不是每次打开页面都实时读取手机。手动在企微修改名称或备注后，需要客户端再次上报并同步，页面才会更新。

## 三个按钮的区别

| 按钮 | 做什么 |
| --- | --- |
| 同步到本页 | 拉取 WorkTool 已有群数据，更新 Console 列表 |
| 读取企微群列表 | 下发客户端读取指令，让手机遍历群列表 |
| 刷新 | 刷新当前页面的数据展示 |

首次补全可在机器人空闲时执行「读取企微群列表」，完成后「同步到本页」。群多时读取耗时较长，不必频繁重复执行；后续可依靠上报逐步补充。

当前搜索按群名、群主查询，群备注展示不等于支持按备注搜索。

## 删除与清空

删除选中仅选择当前页，并按群名删除所有匹配记录；同名群记录可能一起删除。清空群列表清理列表记录。这些操作不会退出或解散实际企微群。后续重新上报或同步仍可能出现记录。

要解散实际群聊，应使用对应指令，并确认业务意图。

## 标签库

标签用于在 Console 中组织群目标，不是企微通讯录标签。先选机器人，创建标签，再维护精确群名或匹配规则。群列表可为选择名称提供参考。

在支持标签的任务中选择标签，可与手动输入目标一起使用，重复目标会合并。动态匹配结果依赖当时平台已有的群数据；执行前先检查群列表是否齐全。

群名及备注可能重复，名称定位不能提供全局唯一群 ID 的保证。批量操作前先在少量目标验证。
