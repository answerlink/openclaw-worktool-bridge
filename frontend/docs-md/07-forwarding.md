# 消息转发

「消息转发」用于把机器人收到的文字按规则转发到其他会话，可与 AI 回复同时使用。它不同于定时任务中的“转发消息”指令。

## 创建规则

1. 选择接收消息的机器人。
2. 选择来源场景：群聊或私聊，并填写来源匹配条件。
3. 如需筛选文字，设置关键词条件。
4. 填写接收目标名称；需要另一台机器人发送时，选择对应发送机器人。
5. 按需开启来源前缀，保存并启用。

目标可以是可定位的群名称、群备注或联系人名称。发送机器人必须能够访问该会话；跨机器人转发不会自动加好友或入群。

## 来源前缀

开启前缀可以让接收方知道消息来自哪里。留空使用默认前缀；自定义模板可使用：

- `{group_name}`：来源群。
- `{sender_name}`：发言人。
- `{source_name}`：当前来源会话名称。

例如：`【{source_name}】{sender_name}：`。

## 验证和停用

在来源会话发送一条符合条件的新文字，查看转发日志，再核对目标会话。日志中的提交成功仍需结合客户端结果判断最终发送是否完成。

自动回复开关不会关闭转发。暂停转发应停用转发规则。配置双向转发时避免形成循环，先用两个测试会话验证。

没有转发时，按顺序检查消息是否进入 Console、规则是否启用、来源与关键词是否匹配、发送机器人是否在线、目标是否可定位。
