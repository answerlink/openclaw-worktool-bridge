# 本地优化验证（2026-08-15）

本轮实现：后台页面按路由动态加载；登录页移除第三方聊天脚本；登录后的聊天组件改为用户点击后创建 iframe；无 token 时同步进入登录流程，减少首次空白。

## 构建变化

| 项目 | 线上基线构建 | 本地优化构建 |
|---|---:|---:|
| HTML gzip | 3.77 kB | 0.46 kB |
| 登录入口 JS gzip | 598.08 kB | 276.39 kB |
| 后台页面 | 全部位于入口包 | 独立路由 chunks |
| 登录首屏第三方聊天 | 立即加载 | 0 请求 |

后台页面已拆成独立文件，其中图表页 `DashboardPage` gzip 约 109.90 kB，仅进入该路由后请求。

## Lighthouse 中位数（每端 3 轮）

| 指标 | 线上移动端基线 | 本地优化移动端 | 变化 |
|---|---:|---:|---:|
| 性能分 | 56 | 92 | +36 |
| FCP | 3,919 ms | 2,256 ms | -42.4% |
| LCP | 4,462 ms | 2,876 ms | -35.5% |
| TBT | 457 ms | 126 ms | -72.4% |
| 总传输量 | 1,797,012 B | 287,706 B | -84.0% |
| JS 执行 | 1,229 ms | 255 ms | -79.2% |
| 主线程 | 2,253 ms | 528 ms | -76.6% |

桌面端本地性能分为 100，LCP 608 ms，TBT 0 ms。

本地与线上来源不同，所以 TTFB、真实网络正文时间不能作为最终发布结论；Lighthouse 的模拟网络/CPU、入口资源体积、JS 执行和主线程降幅可用于部署前方向性验证。最终结论仍需部署到相同线上环境后重新运行脚本。

## Codex 内置浏览器验证

- 未登录页面正常显示登录/注册表单，最终 URL 为 `/login?next=%2F`。
- 登录首屏只有本地主入口脚本，聊天脚本和 iframe 均为 0。
- 通过本机临时假后端登录后，控制台、统计卡片和趋势区正常显示。
- 点击“打开在线助手”前 iframe 为 0；点击后为 1，地址正确；关闭后重新为 0。
- 390 × 844 移动视口下，聊天窗口边界为 350 × 667，完整位于视口内。
- 没有发现本轮改动造成的浏览器运行时错误；控制台仅有项目原有的 React Router 未来版本提示和 Ant Design 静态 message 上下文提示。
